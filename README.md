# MirrorFront

Saves iOS 6 front-camera photos and videos mirrored, exactly as the preview showed them. Works in the lock screen camera too.

## Features

- Front-camera photos and videos are saved mirrored, exactly like the preview.
- Works in Camera and in the lock screen camera.
- Photos stay mirrored when you text or share them.

## How to use

1. Nothing to set up: take a front-camera photo or video and it saves the way the preview looked.

## Requirements

- Jailbroken iOS 6 (tested on an iPhone 5 with iOS 6.1.2)
- Cydia Substrate (Cydia installs them for you)

## Install

In Cydia, add `https://mbucc9000.github.io/slopkit/` and install **MirrorFront**. Or download the `.deb` from [Releases](../../releases) and install it with `dpkg -i`.

## Building

[Theos](https://theos.dev) with the iOS 6.1 SDK: `make package FINALPACKAGE=1`.
